# ZURA — Обзор проекта

## Что такое ZURA?

ZURA — это self-hosted платформа управления задачами и проектами для небольших инженерных команд. Прагматичная альтернатива Jira без корпоративной сложности, непрозрачного ценообразования и vendor lock-in.

Все данные хранятся на вашей инфраструктуре. Вы контролируете сервер, базу данных и пользователей.

## Ключевые архитектурные решения

### Авторизация по email
Username отсутствует. Пользователи входят по email + пароль. Кастомная модель `EmployeeUser` расширяет `AbstractUser` Django с `USERNAME_FIELD = "email"`.

### Две роли пользователей
- **SEO User** — владелец компании. Создаётся при первой регистрации. Может нанимать/увольнять сотрудников, создавать проекты, управлять всеми задачами.
- **Employee** — рядовой участник команды. Работает с задачами, назначенными ему или созданными им. Доступ к проектам, участником которых он является.

### Stateless JWT авторизация
Токены хранятся в `localStorage`. Axios-интерсептор автоматически обновляет access token при получении 401, используя refresh token, без участия пользователя. Refresh-токены ротируются после каждого использования и блокируются.

### Атомарное создание компании
При регистрации SEO-пользователя компания и пользователь создаются в одной транзакции БД. Это исключает частичное состояние (пользователь без компании).

### Сигнальные уведомления
Уведомления создаются автоматически Django-сигналами — без ручных вызовов в бизнес-логике. `tasks/signals.py` срабатывает при изменении исполнителя задачи; `projects/signals.py` — при `m2m_changed` для участников проекта.

### Права создания задач по отделам
Создание задач ограничено по отделу. Рядовые сотрудники могут создавать задачи только если их отдел входит в список разрешённых (Development, QA, DevOps, Design, Management, Business & Analysis, Cybersecurity).

## Локальный запуск

Подробная инструкция по установке — [getting-started.md](getting-started.md).

```bash
# Backend
cd server && source venv/bin/activate && python manage.py runserver

# Frontend
cd client && npm run dev
```

**API документация (требуется запущенный backend):**
- Swagger UI: http://127.0.0.1:8000/docs/
- ReDoc: http://127.0.0.1:8000/redoc/
- OpenAPI Schema: http://127.0.0.1:8000/schema/
